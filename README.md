# riscv64-hpc-ports

Cross-compilation and QEMU validation environment for LFX RISC-V HPC porting project.

## Toolchain
- `gcc-riscv64-linux-gnu` — cross-compiler
- `qemu-riscv64-static` — user-mode emulation for validation
